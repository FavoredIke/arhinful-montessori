# Arhinful's Montessori — Online Admission Website

A responsive school admission website designed for **Arhinful's Montessori**. The project provides an online admission form interface where prospective students or their guardians can enter student information, select school services and indicate co-curricular interests.

## Project Overview

Arhinful's Montessori is a school website concept developed using HTML5 and CSS3.

The website features the school's branding, navigation menu and a structured online admission form. Its layout is designed to provide a simple and organised experience across desktop and mobile devices.

## Features

- **School Branding:** Displays the school's logo, name and motto.
- **Navigation Menu:** Provides links to the main website sections.
- **Student Information Form:** Collects student details, including names, gender, class, telephone number, email and residential address.
- **School Services:** Allows applicants to indicate their preferences for school bus services, canteen, boarding/day arrangements and extra classes.
- **Co-curricular Activities:** Provides activity options such as sports, music, drama, dance, debate and art and craft.
- **Form Controls:** Includes Submit, Update, Search and Reset buttons.
- **Responsive Design:** Uses CSS media queries to adapt the layout to smaller screens.

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:FavoredIke/arhinful-montessori.git
```

### 2. Navigate into the project directory

```bash
cd arhinful-montessori
```

### 3. Open the website

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Current Limitations

This project currently focuses on the frontend interface.

- Admission information is not submitted to a database or server.
- The Update and Search buttons are visual controls without implemented functionality.
- There is no backend integration.
- Some navigation links are placeholders.
